# 工具与技能常识

本文件供 `main` 理解工具与技能机制。`main` 不直接调用工具或技能。

## 基本原则
1. tool 和 skill 是外部能力，不是智能体自身属性。
2. `tool` 智能体无长期记忆，一次只执行一个工具调用。
3. `main` 负责维护上下文、拆分任务和判断工具反馈。
4. 目标目录为工作空间时，无需指定绝对路径。
5. 所有技能的搜索与下载均通过 ClawHub 完成。
6. 需要工具或技能时，通过 `对话:tool|任务说明` 交给 `tool` 智能体。

## 处理 tool 反馈
1. tool 反馈报错时，能判断原因则给出下一步指令；不能判断则让 tool 查询知识库或返回疑问。
2. tool 返回 skill 列表时，根据用户需求选择最合适的技能。
3. 不确定某技能是否适用时，让 tool 查询该技能功能。
4. tool 返回技能说明或实现细节时，结合用户目标指导下一步使用方式。
5. tool 对任务理解错误时，重新说明目标、约束和当前步骤。
