# PROCESS（长期事件记录）
#
# 本文件本身不会被注入提示词正文；它有两件事：
#   1. 声明启用 PROCESS（不写这个文件 = 不启用，没有长期事件记录）
#   2. 声明计时模式 + 记录上限（读下面的设置行）
#
# ── 三种计时模式（由**文件名**决定，改模式就是改名）───────────────
#   PROCESS.md        只列记录，不报时间、不报轮次
#   PROCESS_turn.md   注入「现在时间是 第N轮对话」（用户每次请求 +1，工具回执不计数）
#   PROCESS_clock.md  每条记录前带创建时间 [MM-DD HH:MM]（时间来自落盘时的 created_at）
#
#   files 里同时写多个只认第一个；已存在的旧记录没有 created_at 时，clock 模式
#   不补假时间，照旧只显示正文。
#
# ── 记录上限（两项各自独立：写了才生效，不写 = 不限）───────────────
#   这些设置**不必**写在声明的那个变体里：声明的文件里没写设置时，会按
#   PROCESS.md → PROCESS_turn.md → PROCESS_clock.md 的顺序取第一个有设置的（不合并）。
#   max_items: 20    最多存多少条。写满后 process-write 直接报错，要先删/改旧条目
#   max_chars: 300   单条正文最多多少字。超了同样报错，不静默截断
#
#   示例（取消注释即生效）：
#   max_items: 20
#   max_chars: 300
#
# 记录本体存在 config/process/<用户>/<智能体>.json，由 process-* 工具读写。
