杂项设置

接收图像
开启后，网页与 QQ 发给 main 的图片会以多模态输入传给模型；关闭后图片会被忽略。
main 读取 IDENTITY.md
开启后 main 的系统提示词正常加载 IDENTITY.md；关闭则拦截该文件，仅不加载，不会删除文件。
shell 权限限制
开启后仅下方白名单中的 user_id 可以使用 shell 工具；关闭则不做限制（所有用户可用）。
允许使用 shell 的 user_id
逗号或换行分隔多个 user_id；仅在上方「shell 权限限制」开启时生效。
Windows 宿主机访问权限
开启后仅下方白名单中的 user_id 可以访问 Windows 宿主机：复制/移动写入 /mnt 目录；关闭则不做限制。
允许访问 Windows 宿主机的 user_id
逗号或换行分隔多个 user_id；仅在上方「Windows 宿主机访问权限」开启时生效。
