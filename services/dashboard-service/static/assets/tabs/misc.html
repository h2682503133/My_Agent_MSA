杂项设置

接收图像
开启后，网页与 QQ 发给 main 的图片会以多模态输入传给模型；关闭后图片会被忽略。
main 读取 IDENTITY.md
开启后 main 的系统提示词正常加载 IDENTITY.md；关闭则拦截该文件，仅不加载，不会删除文件。
权限设置已并入「工具权限」
shell 权限、Windows 宿主机访问权限统一在左侧「工具权限」页维护： L3 白名单 = 允许执行（含 shell、生图、删除文件等），L4 白名单 = 允许穿透宿主机（宿主文件、浏览器、dsh、codex）； 名单里写 * 表示对所有用户开放。旧的 shell / 宿主机白名单已在服务启动时自动迁移过去。
